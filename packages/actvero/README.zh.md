# Actvero 桌面集成

[English](README.md) | 中文

## 概述

Actvero 包将桌面工作区连接到平台模型、专家、技能和 MCP 服务。可按所需资源选择对应包；桌面账户与平台服务端由各自模块维护。本组使用 DSH 原生模型、技能和工具服务。
