# 导航、原生选择器和列表加载

[English](README.md) | 中文

## 概述

从桌面侧栏浏览专家、技能和连接器，并为会话选择能力。共享选择器保留当前草稿和附件。原生桥接提供可用资源，凭据不进入渲染器。

## 运行

在官方侧栏注册「能力中心」，集中管理专家、技能和连接器。技能和连接器接入官方「添加」菜单，使用原生可搜索、键盘操作的 popupSelect。选择器只显示能力选项，不包含管理跳转。操作使用打开选择器时捕获的对话；插入技能时保留附件引用并检查草稿版本。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

三个管理器共用来源页签、原生图标与列表骨架屏。技能选择器读取已持有会话的有效目录，包括目录技能与专家固定版本。两种技能入口都插入带技能图标的中性原子徽标；添加时保留已有文字和附件，光标移到徽标右侧。连接器没有配图时使用链接图标，专家行保留头像。必需 MCP 的开关保持开启且不可操作，其他已配置连接器仍可与专家同时选择。

侧栏「工作台」左侧标题进入管理页，右侧名称打开切换菜单。业务组件使用主内容区，标题与返回入口位于顶部同一栏，不要求用户选择文件夹。支持 AI 的工作台首次进入默认展开细长的原生对话浮窗，右上角提供新建对话、全屏对话和收起；标题显示当前对话名称，点击可切换同一业务实例关联的对话，并保留各自草稿。收起后通过右下角品牌图标继续当前对话与输入草稿，悬停时在图标上方提示「使用 AI」。对话通过「＋ → 工作台」选择后显示可移除徽标，默认展示右上角的小型工作台预览，悬停或键盘聚焦时显示展开和收起按钮。AI 浮窗按业务实例、工作台预览按会话与实例分别保存本机显示偏好；再次进入或刷新恢复上次状态，全屏切换不改变偏好。取消使用移除该会话的关联和工具，保留数据。macOS 窗口控件保留安全区域。

工作台管理页与专家管理器共用搜索工具栏、来源页签和响应式卡片网格，图标、间距与操作按钮沿用同一套视觉样式。「我的工作台」提供搜索，分类栏仅在平台目录显示。紧凑卡片提供名称、用途、横向滚动的预览图及打开入口；名称或预览图打开详情。内置「项目清单」提供五张不同进度和深色界面的截图，可用于体验多图切换和放大。图片缺失或加载失败时显示占位。图标、预览和作者等展示信息由工作台注册描述提供，详见[客户端约定](src/contracts.ts)；本地包接入与安装见[工作台说明](../../../actvero/workbenches.zh.md)。

工作台卡片以 Plugin Manager 安装清单为依据，与已注册的业务组件合并；停用和加载失败不会隐藏已安装条目。菜单提供本地版本更新、启停和卸载，确认更新时展示新旧版本。列表读取失败保留上次内容并禁用修改；操作失败、取消和配置覆盖分别报告，不视为生效。替换后的待重启状态由 Host 保留，刷新页面不会清除。操作说明见[本地工作台开发](../../../actvero/workbench-development.zh.md#install)。

Host 配置 `dataDirectory` 指定工作台文件根目录，Actvero Profile 使用其隔离的 `actvero-workbench-data` 目录。Host 为每个工作台保留稳定实例和业务目录；通过 `environment()` 在无会话时也可取得目录、版本和可选资源目录。作者可自行使用文件、SQLite 或远程服务，并组织多个业务项目。原生 Storage Domain 仅保存实例元信息及可选 JSON 适配器的状态；新建自定义存储实例使用 `json: "null"` 元信息占位，不复制业务内容；切换旧 JSON 存储时保留原内容供作者迁移。更新、停用和卸载保留目录；作者负责并发写入、备份和数据迁移。新建对话不会复制清单。已关联对话从 Session 日志恢复所选工作台、版本和内置专家指令。工作台版本不可用时阻止继续请求，重新选择已加载版本后再使用。

工作台作者可设置首次显示建议，并通过 `workbench.display()` 切换业务主界面、原生对话和业务预览，`displayState()` 查询已挂载状态。标题栏可切换专注展示，离开时恢复导航展开状态；AI 与预览分别保存开关和位置。Host 的显示通道只接受本地所有者的可交互客户端，收到真实挂载确认才成功；断线或超时保留未知结果，不自动重放。用法和失败处理见[显示控制](../../../actvero/workbench-development.zh.md#display)。

工作台的公开账户信息与受控模型目录通过宿主提供，模型目录要求 Host 显式声明 `models:read`，只读元信息，不返回凭据或开放任意地址代理。Host 的 `platformTimeoutMs` 默认 30 秒。原生 `develop-workbench` Skill 随包提供，开发入口和模板使用方式见[开发指南](../../../actvero/workbench-development.zh.md#platform)。

<details>
<summary>工作台运行机制</summary>

Host 提供者通过 Cordis effect 注册元信息、可选 JSON 适配器与专家指令。新提供者以 `ai: true` 开启原生对话，缺省关闭；旧式顶层 JSON 接口保持默认开启。新关联会话使用独立的 `.sessions/<instanceId>` 目录，已有会话目录不变。操作携带读取时的修订号；并发修改会被拒绝，要求重读。客户端通过原生 Resource 订阅保存结果，完整页和悬浮预览使用同一组件；预览等比缩小、只读且不滚动，窗口位置可拖动并在本机记忆。原生 Session Projection 恢复关联；会话作用域内注册工具，原生请求记录保留提示词及工具调用。公开接口见[Host 提供者](src/workbench-provider.ts)和[客户端上下文](src/contracts.ts)。

</details>

客户端服务 `ctx.capabilityHub` 打开专家、技能或连接管理器，并显示临时通知。其接口由[客户端约定](src/contracts.ts)定义。

`WorkbenchProvider.activate` 在原生会话作用域内挂载作者能力，返回精确依赖摘要与可选专家指令。绑定完成后才将结果写入关联事件；失败会释放本次注册并保留原关联记录。重复激活复用当前作用域，取消关联或提供者卸载等待资源释放。恢复时摘要变化要求重新选择工作台。通过[随包专家加载器](../../../actvero/workbench-development.zh.md#expert-bundle)可复用原生 Skill、MCP 和解释器，不强制采用通用 JSON 工具。

<a id="model-experience"></a>

## 模型体验

### 原生能力选择

#### 模型能看到什么

管理器和弹出选择器本身不增加模型上下文。选择技能会把原生 `/skill-name` 指令插入草稿；选择专家或连接器会修改该对话由 Host 管理的能力。发送消息仍沿用原生 Session 记录流程。关联工作台后，模型收到所选工作台的名称、版本、可选专家指令与业务操作说明；只有 JSON 适配器会挂载仅对该会话可见的 `workbench_read`、`workbench_action`。自定义存储由作者提供工具和对应说明。业务数据按工具请求读取，不随浏览页面自动发送；账户信息不注入提示词。原生会话日志记录所选环境，后续模型请求保留实际提示词、工具模式和结果。Host 常驻注册 `workbench_list`、`workbench_open`、`workbench_status`，无需先选择工作台。工具结果明确区分确认、失败、取消和未知状态；原生工具卡显示列出、打开或查询工作台。目录仅列 Host 提供者，业务数据不随目录或显示状态发送。

#### Token 影响

浏览管理器和搜索选择器不消耗模型 Token。常驻显示工具的模式进入后续模型请求，调用结果按原生日志记录。发送所选指令或使用已启用能力时，只增加其所属模块描述的原生请求内容。

#### KV Cache 影响

打开或关闭菜单不改变模型请求前缀。能力变更由所属 Host 模块在后续请求中提供不同的指令或工具模式。

## 已知限制和后续工作

<a id="known-limitations-and-deferred-work"></a>

- 能力中心依赖 ACTVERO 原生桥接。工作台账户上下文仅提供当前用户与组织的公开标识，不暴露令牌，也未接入平台图片/视频服务代理、远程分发或发布。随包专家通过显式 `activate` 加载原生依赖，放入目录不会自动启用。基础开发模板仍为独立 UI 示例；原生 AI 联动示例是内置「项目清单」。
