# 导航、原生选择器和列表加载

[English](README.md) | 中文

## 概述

从桌面侧栏浏览专家、技能和连接器，并为会话选择能力。共享选择器保留当前草稿和附件。原生桥接提供可用资源，凭据不进入渲染器。

## 运行

在官方侧栏注册「能力中心」，集中管理专家、技能和连接器。技能和连接器接入官方「添加」菜单，使用原生可搜索、键盘操作的 popupSelect。选择器只显示能力选项，不包含管理跳转。操作使用打开选择器时捕获的对话；插入技能时保留附件引用并检查草稿版本。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

三个管理器共用来源页签、原生图标与列表骨架屏。技能选择器读取已持有会话的有效目录，包括目录技能与专家固定版本。两种技能入口都插入带技能图标的中性原子徽标；添加时保留已有文字和附件，光标移到徽标右侧。连接器没有配图时使用链接图标，专家行保留头像。必需 MCP 的开关保持开启且不可操作，其他已配置连接器仍可与专家同时选择。

侧栏「工作台」左侧标题进入管理页，右侧名称打开切换菜单。业务组件使用主内容区，首次打开不创建会话或要求选择文件夹。支持 AI 的工作台可通过顶部「AI 协助」打开原生对话，或新建关联对话；对话的「＋ → 工作台」也可选择。选中后输入框显示可移除的工作台徽标，右上角提供悬浮查看与进入工作台。收起只隐藏界面；取消使用移除该会话的关联和工具，保留数据。macOS 窗口控件保留安全区域。

工作台管理页与专家管理器共用搜索工具栏、来源页签和响应式卡片网格，图标、间距与操作按钮沿用同一套视觉样式。「我的工作台」提供搜索，分类栏仅在平台目录显示。紧凑卡片提供名称、用途、横向滚动的预览图及打开入口；名称或预览图打开详情。内置「项目清单」提供五张不同进度和深色界面的截图，可用于体验多图切换和放大。图片缺失或加载失败时显示占位。图标、预览和作者等展示信息由工作台注册描述提供，详见[客户端约定](src/contracts.ts)；本地包接入与安装见[工作台说明](../../../actvero/workbenches.zh.md)。

工作台卡片以 Plugin Manager 安装清单为依据，与已注册的业务组件合并；停用和加载失败不会隐藏已安装条目。菜单提供本地版本更新、启停和卸载，确认更新时展示新旧版本。列表读取失败保留上次内容并禁用修改；操作失败、取消和配置覆盖分别报告，不视为生效。替换后的待重启状态由 Host 保留，刷新页面不会清除。操作说明见[本地工作台开发](../../../actvero/workbench-development.zh.md#install)。

Host 配置 `dataDirectory` 指定工作台文件根目录，Actvero Profile 使用其隔离的 `actvero-workbench-data` 目录。业务文档保存在原生 Storage Domain；更新和卸载不删除这些数据。每个提供者目前拥有一份默认业务数据，多条对话可关联它；新建对话不会复制清单。已关联对话从 Session 日志恢复所选工作台、版本和内置专家指令。工作台版本不可用时阻止继续请求，重新选择已加载版本后再使用。

<details>
<summary>工作台运行机制</summary>

Host 提供者通过 Cordis effect 注册初始化、业务操作与可选专家指令。操作携带读取时的修订号；并发修改会被拒绝，要求重读。客户端通过原生 Resource 订阅保存结果，完整页和悬浮页使用同一组件。原生 Session Projection 恢复关联；会话作用域内注册工具，原生请求记录保留提示词及工具调用。公开接口见[Host 提供者](src/workbench-provider.ts)和[客户端上下文](src/contracts.ts)。

</details>

客户端服务 `ctx.capabilityHub` 打开专家、技能或连接管理器，并显示临时通知。其接口由[客户端约定](src/contracts.ts)定义。

## 模型体验

### 原生能力选择

#### 模型能看到什么

管理器和弹出选择器本身不增加模型上下文。选择技能会把原生 `/skill-name` 指令插入草稿；选择专家或连接器会修改该对话由 Host 管理的能力。发送消息仍沿用原生 Session 记录流程。 关联工作台后，模型收到所选工作台的名称、版本、可选专家指令与业务操作说明，以及仅对该会话可见的 `workbench_read`、`workbench_action`。业务数据按工具请求读取，不随浏览页面自动发送；账户信息不注入提示词。原生会话日志记录所选环境，后续模型请求保留实际提示词、工具模式和结果。

#### Token 影响

浏览管理器和搜索选择器不消耗模型 Token。发送所选指令或使用已启用能力时，只增加其所属模块描述的原生请求内容。

#### KV Cache 影响

打开或关闭菜单不改变模型请求前缀。能力变更由所属 Host 模块在后续请求中提供不同的指令或工具模式。

## 已知限制和后续工作

<a id="known-limitations-and-deferred-work"></a>

- 能力中心依赖 ACTVERO 原生桥接。工作台账户上下文仅提供当前用户与组织的公开标识，不暴露令牌，也未接入平台图片/视频服务代理、远程分发或发布。内置专家目前是随包指令；MCP、Skill、CLI 不因放入目录而自动加载。基础开发模板仍为独立 UI 示例；原生 AI 联动示例是内置「项目清单」。
