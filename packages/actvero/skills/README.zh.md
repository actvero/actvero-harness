# 技能安装与版本管理

[English](README.md) | 中文

## 运行

管理平台目录、指定版本安装、更新检查、启停以及本地 ZIP、文件夹、Markdown 导入。采用前校验包摘要和路径。当前安装与不可变版本记录按平台、账户和组织隔离；旧专家快照加载其记录的版本。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

专家 ZIP 导入通过同一个包校验器暂存每个嵌入的单技能，内容完全相同的已安装技能会复用。导出校验原始文件摘要，不嵌入平台技能副本。归档辅助方法只在 Main 中使用，不执行导入内容。

「本机技能」也读取原生会话目录中的项目 `.agents/skills`、`.dsh/skills`，全局 `~/.agents/skills`、`$DSH_HOME/skills`，自定义目录及嵌入式提供方。目录技能显示来源路径，可通过原生文件预览打开原始 `SKILL.md`。这类技能无需导入，管理器不复制、上传或卸载原目录文件；安装控制仍仅用于受管理的包。专家固定版本优先于同名发现技能，其他目录技能仍可使用。目录发现与优先级由 [skill-filesystem](../../skill/skill-filesystem/README.zh.md)负责。

## 模型体验

### 精确技能加载

#### 模型能看到什么

原生技能服务发布已授权且启用的技能简介，并返回所选版本经过校验的 `SKILL.md` 指令和资源目录。客户端管理器的搜索、分类和安装界面不会进入模型上下文。

#### Token 影响

原生技能消费者负责目录和已加载指令的 Token 消耗；下载或安装包不会创建模型请求。专家使用自己的精确版本内容，而不是当前安装版本。

#### KV Cache 影响

目录或指令变更可能改变原生消费者的请求内容。专家保持所记录的版本并重新校验授权；仅刷新管理器不改变请求前缀。

## 已知限制和后续工作

- 加载平台技能时检查当前授权，归档版本也一样；断网可见安装状态不代表允许执行。停用或卸载阻止该安装，服务端撤销不删除本地文件。旧快照使用的归档包可能保留。本地导入仅属于本设备。
