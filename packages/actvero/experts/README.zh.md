# 专家与对话版本快照

[English](README.md) | 中文

## 概述

创建、导入或选择包含指令、技能和连接器要求的专家。会话保留精确的专家快照，用于恢复和分叉。执行前，必需依赖必须仍然可用且具备授权。

## 运行

保留原有本地、平台专家管理、ZIP 与旧版 JSON 导入、开场问题和 AI 创建。原生专家选择器按记录顺序显示最近召唤的专家，不包含标准模式或管理跳转。召唤时保留当前空闲会话和工作区，不要求额外选择目录。已开始的空闲对话也可切换专家，历史保持不变。已安装工作台的随包专家显示来源和工作台图标。专家未提供简介时沿用工作台简介。其生命周期由工作台管理，不支持作为个人专家单独删除。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

详情对话框的召唤、导出和本地专家删除按钮采用相同的原生尺寸，间距为 8px。删除前需要确认，只移除本地专家记录，已有对话快照和已安装的技能、MCP 连接器都会保留，因此同一个专家包可以再次导入。最近选择器行显示专家头像，缺图时用首字默认头像。输入框在权限按钮前显示专家头像和名字，工具栏空间不足时只显示头像。点击名字或折叠后的头像可打开原生选择器，不改变草稿。选择器内可停止使用专家；展开时也可在悬停或键盘聚焦后通过头像位置的移除按钮停用。移除后，后续请求不再使用专家。切换对话连接器后菜单保持打开；必需依赖显示带本地化说明的禁用开启开关。关闭选择在回放、分叉和下次激活后保留，与连接健康状态分开。

ACTVERO 桌面端不会预置或自动复制默认专家。本地专家通过创建或单专家 ZIP／JSON 导入进入“我的专家”。

原生 `expert_create` 接收名称、简介、提示词、已安装的 Skill 和 MCP ID，以及可选头像文件路径。Harness 校验依赖、生成清单和绑定，并返回专家 ID、修订号和头像状态。召唤时使用这个 ID 在新会话核对核心 Skill 和样例输出。

点击「创建专家」先选择创建方式。「在 Harness 中创建」在输入框中插入可移除的 `expert-creator` 技能标签和一段可编辑的请求；「交给其他 Agent」复制本机技能入口和开发连接，供外部 Agent 通过 CLI 维护专家或交付可导入的专家文件。生成的 JSON 通过导入流程核对并绑定本机能力。把模板里的专家类型、主要工作和期望结果换成自己的需求，再发送。创建技能先根据已有上下文了解使用场景、输入和交付标准。仅有专家名称或笼统用途时，优先用当前会话的提问工具提出关键问题并等待有效回答。没有提问工具时用聊天询问。技能先核对本机 Skill、MCP 和当前会话工具。遇到能力缺口、影响选型的候选或用户希望借鉴成熟做法时，按可用来源调研外部资源。专家方案说明工作流程、交付标准、可复用能力和需要新增的依赖。新建专家或修改职责、流程、依赖时，先给用户看方案，再用同一提问入口确认，随后按授权实施。已提供完整方案并要求保存时，直接沿用该方案。技能支持用真实任务试用后继续改进；保存成功、依赖就绪和实际试跑分别报告。确认方案时，技能会核对当前对话能否生成图片并取回结果。可以生成时，用户可选「生成头像」「我提供图片」或「使用默认头像」。没有可用的生成工具时，用户可提供图片或使用默认头像。已提供的图片直接沿用。桌面会话和外部 Agent 均可读取完整的技能目录，包括方案模板、工具指南、案例和导入验证脚本。

可以按名称或 ID 请该技能改造已有专家。对于「我的专家」，技能读取当前修订号，保存指定字段，再检查已保存的依赖。提交的数组或绑定映射会整体替换对应的值。修订号过期时保存会失败。对于指定平台组织，技能调用独立安装并已登录的 `actvero` CLI 管理专家草稿、技能版本和 MCP 配置。请求字段和命令用法可从 CLI 自带帮助查询。

平台详情仅在发布 ID 和摘要均相同时复用准备状态。切换发布会清除准备记录并重新解析精确依赖；已安装的技能版本通过文件和摘要校验后可以复用。当前缓存恢复先校验账号、专家发布内容及同平台专家地址，并成功获取选定发布，再丢弃混用发布的准备状态。摘要损坏、外部地址和其他账号记录仍被拒绝。并发准备共用操作，账号或发布变化会阻止过期操作提交。每次召唤都会检查选定发布。对话快照保留原发布及其权限校验。

一次召唤仅在 Main 管理的本次选择操作内复用已校验的运行内容。准备、激活和 Host 最终检查共享结果；操作完成、失败、账号变化或技能安装状态变化后立即失效。后续模型执行仍会校验当前授权和精确文件。本地准备只读取已绑定技能，专家没有连接器依赖时跳过连接器发现。最新发布版本的解析结果同时提供依赖和更新状态，无需逐个技能重复查询目录。

选中专家后，将其精确技能版本与连接器要求合并到原生能力中，不隐藏其他原生技能或已添加的 MCP 配置。同名技能加载经过校验的专家版本；固定版本校验失败时仍拒绝该视图，不回退到发现内容。

Host 适配器 `ctx.actveroExpertPolicy` 根据专家快照和会话选择解析 Agent 允许使用的连接 ID。未定义的选择沿用普通连接策略；空选择不允许任何连接。其对象接口与提供者位于 [Host 插件](src/index.ts)。

平台目录卡片对比本机保留的版本与最新发布，显示版本变化；打开或刷新目录时通过 DSH Toast 提示更新。查看详情不会清除更新状态，准备成功后才更新本机版本记录；准备窗口显示前后版本。已有对话继续显示快照中的名称、版本与头像。清单接受的头像也均可保存到会话投影。

`@actvero/dsh-experts/workbench` 的 `WorkbenchExpertBundle` 为本地工作台加载随包指令、原生 Skill、MCP 与 CLI 说明。作者将 `bundle.activate` 交给工作台提供者的 `activate`；资源按工作台版本缓存，能力按关联会话注册并随其作用域释放。原生 Skill 和 MCP 复用宿主的 peer 实例。该入口不依赖 Main 专家记录，也不切换普通专家选择；同一对话可叠加普通专家和工作台环境。完整目录、固定摘要、取消与失败规则见[本地工作台开发](../../../actvero/workbench-development.zh.md#expert-bundle)。

## 模型体验

### 专家角色与依赖

#### 模型能看到什么

Host 把所选专家的名称、版本、指令以及始终加载的已验证技能块加入 `actvero_expert` 系统提示变量，并提供限定范围的 MCP 能力，以及 `expert_catalog`、`expert_create`、`expert_list`、`expert_get`、`expert_update`、`expert_check` 本地专家工具。专家详情返回头像状态。图片编码不进入详情结果。原生 Session 投影记录不可变专家选择与有作用域的连接器选择。专家必需连接器保持开启；可选连接器可以在此对话中关闭。

#### Token 影响

专家指令、始终加载的技能内容、所选工具模式和返回结果会增加原生请求的 Token。仅浏览或选择专家不会提交一轮对话。

#### KV Cache 影响

原对话开始后选择其他专家会创建新对话。恢复和分叉保持记录的专家快照，上游发布新版本不会自动重写其角色或依赖内容。

## 已知限制和后续工作

<a id="known-limitations-and-deferred-work"></a>

- 专家指定快照及依赖引用写入 actvero/expert 会话事件，通过官方投影注册表读取。恢复和分叉保留快照，新发布不会替换旧对话依赖。执行前再次检查资源权限。发布 v3 要求验证 MCP 各能力类型的语义引用。本地专家使用[单专家包格式](../../../actvero/expert-package.zh.md)导入导出。新增 MCP 模板保存为关闭状态。平台依赖保留指定引用且需要当前授权；导入不会上传到平台。
