# 专家与对话版本快照

[English](README.md) | 中文

## 概述

创建、导入或选择包含指令、技能和连接器要求的专家。会话保留精确的专家快照，用于恢复和分叉。执行前，必需依赖必须仍然可用且具备授权。

## 运行

保留原有本地、平台专家管理、ZIP 与旧版 JSON 导入、开场问题和 AI 创建。原生专家选择器按记录顺序显示最近召唤的专家，不包含标准模式或管理跳转。从对话召唤时沿用其工作区；管理页仅在无法确定时询问。已开始的对话会创建新的专家对话。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

详情对话框的召唤、导出和本地专家删除按钮采用相同的原生尺寸，间距为 8px。删除前需要确认，只移除本地专家记录，已有对话快照和已安装的技能、MCP 连接器都会保留，因此同一个专家包可以再次导入。最近选择器行显示专家头像，缺图时用首字默认头像。输入框通过原生左侧插槽在权限前显示专家头像和名字。悬停或键盘聚焦时，头像变成移除按钮；点击名字重新打开同一个原生选择器，不改变草稿。移除后，后续请求不再使用专家。切换对话连接器后菜单保持打开；必需依赖显示带本地化说明的禁用开启开关。关闭选择在回放、分叉和下次激活后保留，与连接健康状态分开。

ACTVERO 桌面端不会预置或自动复制默认专家。本地专家通过创建或单专家 ZIP／JSON 导入进入“我的专家”。

平台详情仅在发布 ID 和摘要均相同时复用准备状态。切换发布会清除准备记录并重新解析精确依赖；已安装的技能版本通过文件和摘要校验后可以复用。当前缓存恢复先校验账号、专家发布内容及同平台专家地址，并成功获取选定发布，再丢弃混用发布的准备状态。摘要损坏、外部地址和其他账号记录仍被拒绝。并发准备共用操作，账号或发布变化会阻止过期操作提交。每次召唤都会检查选定发布。对话快照保留原发布及其权限校验。

选中专家后，将其精确技能版本与连接器要求合并到原生能力中，不隐藏其他原生技能或已添加的 MCP 配置。同名技能加载经过校验的专家版本；固定版本校验失败时仍拒绝该视图，不回退到发现内容。

Host 适配器 `ctx.actveroExpertPolicy` 根据专家快照和会话选择解析 Agent 允许使用的连接 ID。未定义的选择沿用普通连接策略；空选择不允许任何连接。其对象接口与提供者位于 [Host 插件](src/index.ts)。

## 模型体验

### 专家角色与依赖

#### 模型能看到什么

Host 把所选专家的名称、版本、指令以及始终加载的已验证技能块加入 `actvero_expert` 系统提示变量，并提供限定范围的 MCP 能力和 `expert_catalog`、`expert_create` 本地创建工具。原生 Session 投影记录不可变专家选择与有作用域的连接器选择。专家必需连接器保持开启；可选连接器可以在此对话中关闭。

#### Token 影响

专家指令、始终加载的技能内容、所选工具模式和返回结果会增加原生请求的 Token。仅浏览或选择专家不会提交一轮对话。

#### KV Cache 影响

原对话开始后选择其他专家会创建新对话。恢复和分叉保持记录的专家快照，上游发布新版本不会自动重写其角色或依赖内容。

## 已知限制和后续工作

<a id="known-limitations-and-deferred-work"></a>

- 专家指定快照及依赖引用写入 actvero/expert 会话事件，通过官方投影注册表读取。恢复和分叉保留快照，新发布不会替换旧对话依赖。执行前再次检查资源权限。发布 v3 要求验证 MCP 各能力类型的语义引用。本地专家使用[单专家包格式](../../../actvero/expert-package.zh.md)导入导出。新增 MCP 模板保存为关闭状态。平台依赖保留指定引用且需要当前授权；导入不会上传到平台。
