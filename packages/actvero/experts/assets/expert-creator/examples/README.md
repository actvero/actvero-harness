# 设计案例

进入方案设计阶段后，按目标任务读取最接近的案例。提取其职责划分、渐进式结构和试跑办法。案例中的连接器名称表示要查证的能力类别，真实依赖从当前环境中查找和验证。

| 你在设计什么 | 先看哪个案例 | 重点看什么 |
| --- | --- | --- |
| 需要直接对照完整方案、真实 MCP 方法及可导入文件 | [版本发布说明编辑](release-notes/proposal.md) | 完整提示词、业务 Mermaid 图、Skill 和工具清单，以及能试导入的 ZIP 示例 |
| 从材料出稿、借用成熟流程、复用组织模板 | [活动新闻稿专家](press-release.md) | 文档 MCP 取资料、Skill 核查和写作、参考模板按发布渠道加载 |
| 多来源取数、取证、形成简报 | [企业调研专家](company-research.md) | 公开搜索与内部系统权限、证据复核、结果降级 |
| 本地数据处理、工作台和随包专家 | [本地交付巡检工作台](workbench-delivery/README.md) | Skill 指导流程、脚本做确定性检查、内置 CLI 交付工作台 |
