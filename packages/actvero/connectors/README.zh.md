# MCP 连接与对话选择

[English](README.md) | 中文

## 概述

添加平台或本地 MCP 连接，并选择哪些会话可以使用它们。通过协商后的 MCP 协议发现工具、提示词和资源。设备启用状态与当前授权继续约束每个会话的选择。

## 运行

管理平台 MCP 服务和本地 stdio、Streamable HTTP、SSE 配置。发现能力完整保留 Tools、Prompts、Resources、Resource Templates，并支持分页。调用前协商协议版本和能力。选择的能力仅注册到对应智能体作用域，调用保留取消支持。

通过 ACTVERO 桌面组合启用（`ACTVERO_DESKTOP=1`）。Electron 主进程提供资源权限；客户端不读取相邻仓库，也不保存 Bearer 令牌。

对话开关通过原生 Session 事件保留选择，支持 Host 重启和分叉；专家必需依赖在选择器中保持开启且不可操作。平台选择按平台、账号与组织隔离。对话选择不授予权限，也不会全局启用关闭的配置。专家 ZIP 模板去除凭据值、拒绝设备专属路径，并要求 stdio 包固定版本。新模板保存为关闭状态，不启动进程或 OAuth 流程。

本机 MCP 配置由 Electron Main 使用系统加密保存。文件不存在时使用空初始状态；安全存储不可用与文件无法解密分别报告错误，并保留原始密文。查询失败时保留已经加载的列表。

平台连接器与本机连接器使用相同的来源页签和卡片布局。本机卡片显示设备启停开关与连接状态，直接打开原配置表单。选中专家后，对话选择器仍显示所有已添加连接器，并在对应条目上合并专家依赖要求。必需依赖保持开启且不可操作，可选依赖和额外连接器保留对话作用域内的选择。目录刷新失败时提供重试，不丢弃已加载的列表。

Host 适配器 `ctx.actveroMcp` 刷新 Agent 范围内的注册，并返回会话已注册的连接 ID 和工具名。它将授权和发现交给 Electron Main，并在注册与执行前应用专家策略。其对象接口声明在 [Host 插件](src/index.ts) 中。

## 模型体验

### 对话作用域内的 MCP 能力

#### 模型能看到什么

Host 为被允许的 agent 注册 MCP 工具、提示词、资源和资源模板，使用从连接和能力生成的 `mcp_` 名称。调用通过原生工具运行时返回规范 MCP 结果。个人令牌和 OAuth 状态不进入这些模式或结果。

#### Token 影响

启用的能力模式和返回内容通过原生工具消耗模型 Token；浏览连接器管理器、授权和连接测试不会创建模型请求。

#### KV Cache 影响

启用的能力集合变更会改变后续工具模式，可能影响缓存前缀。复用个人连接避免重复初始授权，但仍执行当前权限校验。

## 已知限制和后续工作

<a id="known-limitations-and-deferred-work"></a>

- 平台令牌与上游凭据由 Electron 主进程持有。个人授权在失效前复用。发现能力暂时失败时保留已有目录，实际调用仍检查授权。对话选择通过 Session 事件恢复；专家依赖通过指定快照恢复。从设备移除服务与断开个人授权的范围不同。
