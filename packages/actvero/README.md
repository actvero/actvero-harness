# Actvero desktop integrations

English | [中文](README.zh.md)

## Summary

Actvero packages connect the desktop workspace to platform models, experts, skills and MCP services. Choose the package for the resource you need; the desktop account and platform server remain separate owners. The group uses native DSH model, skill and tool services.
