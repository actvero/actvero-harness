# 单专家 ZIP 格式

[English](expert-package.md) | 中文

## 包内文件

本文定义用于一个本地专家的 `actvero-expert` 第 1 版格式。导入使用 Electron 原生文件选择器；包内字节、路径和预览令牌由主进程管理。导出使用原生保存窗口。预览、导入不会执行包内命令，也不会上传内容到平台。

```text
package.json
expert.json
dependencies.json
skills/<key>/SKILL.md
skills/<key>/references/...
connectors/<key>.json
```

`package.json` 包含 `format: "actvero-expert"`、`schemaVersion: 1` 和 `files: [{ path, size, sha256 }]`。文件列表覆盖除 `package.json` 本身之外的全部文件。SHA-256 使用原始字节的小写十六进制摘要。未列出的文件、归一化后重复的路径、绝对路径、路径穿越、符号链接和摘要不匹配均会拒绝导入。

`expert.json` 使用现有专家管理器接受的严格 ExpertManifest v1。每项依赖声明稳定 key、名称和是否必需；技能还声明 `always` 或 `on_demand` 加载方式。导入生成新的本地专家标识；清单和最终依赖绑定都相同时复用已有专家。

`dependencies.json` 包含 `schemaVersion: 1`、`skills` 和 `connectors` 数组。每项具有对应需求的 `key`，以及 `source: "local"` 或 `"platform"`。本地项使用 `path`：`skills/` 下的技能目录，或 `connectors/` 下的一份 JSON 模板。技能目录必须只含一个标准 `SKILL.md`，复用单技能校验器。平台项不包含本地路径，仅保存 `platform`、`id` 和 `sha256`；技能另外保存 `versionId`。平台 MCP 摘要标识已保存的能力清单，不是平台发布版本标识。

桌面受管的 FreeCAD MCP 是例外：专家的 `expert.json` 可以声明 `freecad-mcp` 为必需连接器，而 `dependencies.json` 不需要携带本机启动命令或凭据。导入明确需要该连接器的专家时，桌面端会从已安装的 FreeCAD 设计环境恢复并注册受管连接器，再把它绑定到专家。ZIP 不会携带 FreeCAD、Python 环境、桌面权限或令牌，也不会执行 ZIP 内的任意命令；如果本机尚未安装 FreeCAD 设计环境，导入仍会提示先完成环境安装。

## 导入与复用

预览列出复用、安装、同名冲突和缺少授权。已启用的同名本地技能仅在完整文件内容相同时复用。同名 MCP 仅在可移植配置相同时复用，名称比较不区分大小写。内容不同会阻止导入，不覆盖已有配置。必需的平台依赖未解析时阻止导入；可选依赖可暂不绑定。复用平台依赖要求平台地址相同、技能安装版本或 MCP 能力清单一致，并且当前仍有授权。

确认时重新检查预览、平台以及账号／组织作用域。缺少的本地技能通过现有安装器安装。新增 MCP 模板保存为关闭状态；填写凭证并启用仍是管理器中的独立操作。对于桌面内置的一方连接器，环境助手可以先注册并验证本机连接，导入时按稳定依赖 key 自动复用该连接器，不再创建重复模板。专家最后保存。失败时仅回滚此次新建、且没有专家引用的依赖；清理失败会提示手动检查。已有专家与共享依赖保留。

## 可移植 MCP 模板

模板仅包含配置和空凭证字段，不包含已保存的令牌、OAuth 会话、凭证值或本机工作目录。导出清空环境变量／请求头的值，保留字段名与认证要求。导入拒绝含凭证的模板。远程模板使用不含账号密码或查询参数的 HTTP／SSE 地址。Stdio 模板允许 `npx`、`uvx` 和指定版本的包，以及可选 `-y`／`--yes`；任意命令、本机路径、脚本和其他启动参数需在此格式之外手动配置。保存模板不会启动命令或 OAuth。

## 限制与归属

ZIP 压缩后不超过 20 MiB，解压后不超过 40 MiB，最多 500 个文件，每个文件最多 5 MiB。专家元数据 JSON 不超过 700,000 字节。每种依赖最多 32 项。同时最多保留三个预览，十分钟过期；切换账号使预览失效。包内是一个专家，不是技能分发实体。平台专家发布导出、自动上传云端、冲突替换和依赖迁移不属于此格式。旧对话保留不可变快照，使用平台依赖前仍检查当前访问权限。
