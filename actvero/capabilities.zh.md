## 已实现行为

专家、技能和连接器共用官方侧栏的管理器入口，保留已有目录、分类、搜索、详情、本地导入和连接流程。官方输入框的添加菜单贡献专家、技能和连接器命令，均使用原生可搜索弹出选择器，支持键盘导航、Escape 和点击外部关闭。连接器行使用原生对话开关，切换后保持菜单打开。专家必需连接器显示灰色不可操作的开启开关；可选连接器关闭后下次激活仍保留。专家选择器显示最近召唤，不含标准模式或管理入口。输入框显示头像和名字标签：悬停或键盘聚焦时可移除，点击名字重新打开原生选择器。移除后，后续请求不再使用专家。桌面端不会预置或自动复制默认专家；本地专家通过创建或导入进入“我的专家”。插入技能会保留已有附件引用并检查草稿修订。对话中召唤专家使用该对话的工作区；只有管理器无法确定工作区时才询问。已准备的依赖不会仅因再次召唤专家而重复弹出准备窗口。

三种目录列表共用骨架占位。连接器刷新遇到暂时查询失败时保留原来的条目。已接入的操作结果使用原生全局 Toast，字段校验和查询重试保留在其所属界面。

## 运行时职责

`packages/actvero/capability-ui` 负责导航和共用展示，`skills`、`connectors`、`experts` 负责可执行的领域职责及原生客户端贡献。Electron Main 负责资源令牌申请、业务连接加密存储、本地包安装和 OAuth 回调。渲染器桥接仅开放固定且有边界的操作，不返回访问或刷新令牌。Host 注册原生技能视图、系统提示及按 agent 隔离的 MCP 工具。只有 `ACTVERO_DESKTOP=1` 时才加载这些模块，普通官方产品不加载。

`@actvero/dsh-model-gateway` Host 插件注册 DSH 原生 `LlmAdapter` 路由 `actvero-platform`，在界面显示为“平台模型”。它使用 `llm:catalog` 令牌读取平台模型目录，为选中的模型申请 `llm:<uuid>` 令牌，并通过平台地址发送 OpenAI 兼容的流式对话请求。模型模态、上下文窗口和思考选项来自目录能力；平台授权、路由、额度和价格仍由服务端负责。

平台、账号和组织切换会使运行时的所属上下文失效。不从旧应用配置中导入凭证，生产构建和运行时代码不读取相邻仓库。

## 版本与授权

平台技能安装校验版本标识、SHA-256 摘要和包路径安全。更新当前安装版本会保留旧专家锁使用的不可变版本记录。加载所记录的版本仍校验当前授权及文件，已安装副本或归档不提供离线执行授权。撤权阻止使用，不删除本地文件。

专家采纳锁定发布版本、精确技能版本和能力引用。原生 Session 投影恢复和分叉所记录的快照。已经开始的对话不会因选择另一个专家而改写，召唤会在相同工作区开启新对话。远程校验采用 Skills 访问契约 2 和 Experts 访问契约 3，包含 MCP 能力语义校验。不兼容或撤权的依赖会失败，不回退到目录最新内容。

本地 MCP 通过 MCP SDK 支持 stdio、Streamable HTTP、SSE、个人 OAuth/PKCE 刷新以及 Tools、Prompts、Resources 和 Resource Templates。每次业务调用检查当前对话策略和个人授权。复用已建立的连接避免多余的初始登录提示，但失效或被撤销的授权仍可能要求重新连接。

原生 `actvero/connectors` 事件让普通对话与专家对话的开关选择在 Host 重启和分叉后保留。平台选择按平台、账号与组织隔离，本地选择使用本地作用域。选择本身不授予权限，也不会全局启用关闭的 MCP 配置。本地专家支持[单专家 ZIP 格式](expert-package.zh.md)和旧版 JSON 导入。不包含市场与自动上传到平台。
