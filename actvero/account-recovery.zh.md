# ACTVERO 登录恢复

[English](account-recovery.md) | 中文

## 持久化

Electron 主进程在独立 Electron 用户目录的 `actvero-device-account.enc` 中保存设备会话、所连接的服务、登录取消证明与续期恢复记录。必须使用系统加密，不降级到明文。原子替换会同步文件，在 POSIX 下还同步所在目录。渲染进程仅获取账户资料与额度状态。

续期 v2 在发送前保存原 refresh 和请求 UUID，在确认前保存后继凭据；崩溃后使用同一 UUID 重试原请求，或继续确认已保存的后继凭据。恢复所得 access 有效期为零时，先保存结果再发起新的轮换。所有窗口共用一个串行控制器和一个续期请求。

断网、限流和临时服务故障保留凭据。设备或账号的确定失效会清理授权并要求登录。续期重放冲突保留恢复记录。退出先使在途结果失效，再清理本机授权；尚未完成的远端撤销加密保存，只向原服务重试。

资源令牌申请共用续期队列。服务端拒绝过期的短期访问令牌时，续期并重试一次。临时离线后，申请资源前重新验证账号；即使账号和组织未变，可用状态变化也会通知目录订阅方刷新。服务端确实要求重新认证时，进入账号登录流程。浏览器确认完成前仍禁止签发任何资源令牌。

## 平台输入

已提交的 [OpenAPI 子集](contracts/desktop-openapi.json)定义设备账户数据。运行 `pnpm exec tsx scripts/actvero-contract.ts` 生成类型，加 `--check` 检查是否过期。修改消费代码前，先从平台交付更新快照。登录使用契约版本 1，续期使用恢复版本 2。构建配置的名称和标志优先于匿名 `/api/v1/auth/session` 返回的平台品牌；同源 PNG/JPEG/WebP 平台图标在不发送凭据的情况下下载，限制为 2 MiB，向界面提供内嵌图片数据，不使用组织图标。

## 浏览器返回页

本地浏览器页面沿用官方桌面完成页布局，使用 ACTVERO 文案。主进程收到回调后交换临时设备会话，并通过 `/desktop/me` 验证身份，再显示账号及“继续使用此账号”“切换账号登录”。浏览器已有的单点登录仍可复用，但不会直接进入桌面；用户确认后接受设备会话，组织验证完成后进入工作区。新输入账号密码的成功登录也经过这次浏览器确认。“返回桌面端”使用现有 `dsh://open` 唤起入口；授权取消时只显示未完成提示并返回登录。

临时设备会话加密保存 `browserPending` 标记，在确认前不能进入工作区、选择组织、查询额度或打开个人中心。取消、切换账号或应用重启会撤销它；远端撤销失败则保留队列，仅向原平台重试。主进程接受继续操作前重新验证所展示的身份。浏览器仅收到姓名和可选邮箱，不获得凭据、身份标识或 OAuth 证明。本机选择通过独立随机页面路径、HttpOnly SameSite Cookie、独立 CSRF 值、严格同源 POST 校验及串行决策保护。页面清除授权参数，不加载远程资源，并保留基于内容哈希的安全策略；不需要修改平台 API 或认证契约。

## 登录入口与账号确认

登录窗口左侧复用原桌面的流动背景，右侧使用 DSH 原生字体、颜色与按钮。宽度不足时隐藏装饰区；减少动态效果、窗口不可见或绘图不可用时停止动画并保留原图。浏览器返回页复用同一素材和动画，不请求外部资源。

启动时正常恢复保存的设备会话与已选组织，然后显示账号资料，由用户点击“继续使用此账号”进入工作区。后台续期不关闭这个确认页，也不打开浏览器。本次浏览器登录在浏览器明确确认账号、可用组织验证完成后直接进入工作区，不在桌面重复确认账号；有多个且未保存有效选择时先选择组织。确认退出后立即回到登录页，远端撤销尚未完成也不影响；再次打开仍显示登录页，直到用户登录或主动选择使用本地工作区。

“切换账号登录”先加密保存当前设备的撤销记录和重新验证标记，再清理本机账号并通过 `reauthenticate=true` 发起浏览器登录。取消切换后原账号不会悄悄恢复。安全存储写入失败时保留原账号，不打开新登录；远端撤销失败会向原服务重试。本机文件与对话不受影响。

“退出登录”使用桌面现有确认弹窗。取消、按 Esc 或关闭弹窗均保留当前账号，不发送撤销请求。重复点击共用一个弹窗；账号环境已改变或应用已关闭时，迟到的确认不会执行退出。只有明确确认后才开始本机退出和远端清理。

## 聚焦验收

```sh
pnpm exec vitest run apps/desktop/tests/actvero-account.spec.ts apps/desktop/tests/actvero-account-policy.spec.ts scripts/actvero-product.spec.ts
pnpm exec vitest run --config vitest.e2e.config.ts apps/desktop/tests/actvero-account.e2e.ts
pnpm exec tsc -b apps/desktop/tsconfig.json
```

Host 产物测试需要先成功构建仓库；测试装配临时官方桌面项目，验证 ACTVERO 账户产物与原官方基线。合成测试覆盖轮换崩溃、退出后迟到结果、组织切换、PKCE 和回调校验，不代表真实经过 30 天或已验证 Windows 安全存储。

原生验收需登录所选测试平台，退出隔离开发版，再以同一配置重启，确认自动恢复同一账号与组织且不弹浏览器。检查账户菜单、额度查询、地址表单、Escape 与点击外部关闭，以及深浅主题。在测试设备会话上验证服务故障与撤销，保留现有安装数据。
