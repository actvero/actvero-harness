# ACTVERO 平台技能安装路径

[English](guide.md) | 中文

## 变更

新的平台技能安装在账号技能目录下使用 `p/<32-hex-id>`，替代 `packages/<skill-id>/<installation-id>`，以缩短 Windows 路径。新版桌面端支持两种目录格式，已有包保留原位。旧版桌面端会拒绝包含紧凑路径的安装记录；不支持让旧版程序共用更新后的用户数据目录。

## 迁移

1. 安装新的平台技能版本前，先升级 ACTVERO 桌面端。无需手动搬迁文件或修改注册表。
2. 召唤专家，确认必需技能可用。已有会话快照保持其精确版本与路径。
3. 如需降级，使用单独备份的升级前用户数据目录。不要手动改写安装记录或搬迁包目录。
