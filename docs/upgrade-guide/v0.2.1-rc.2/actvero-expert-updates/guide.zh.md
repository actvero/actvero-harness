# ACTVERO 专家包更新

[English](guide.md) | 中文

## 变更

ACTVERO 以前在导入专家 ZIP 时拒绝内容不同的同名依赖。现在桌面记录包的来源 `id`，对比 `version`，并展示依赖更新计划。已有对话保留精确版本。

本地技能更新后，`actvero-capabilities/skills/local/installed.json` 保存当前版本及保留的 `previous` 条目。新文件位于 `versions/<skill-id>/<version-id>`，原包目录保留。专家记录增加由主进程管理的 `packageOrigin` 基线。旧桌面不支持这些记录。会话事件及可移植 ZIP 格式不变。

## 迁移

1. 升级时保留完整桌面用户数据目录。不要通过删除或改写技能安装记录来解决导入冲突。
2. 包作者沿用 `expert.json` 的 `id`，内容变更时提高三段 `version`。导入 ZIP 并检查显示的变更。缺少来源记录的旧专家，仅在本机有唯一同名专家时可关联更新。
3. 先处理标记的本地修改或共享依赖冲突。变化的 MCP 模板新建带版本标识的停用配置，在连接器管理页检查、授权并启用新连接。
4. 确认「我的专家」显示导入版本，再在新对话中召唤。已有对话保留快照。更新后的本地索引需使用本版或更新的桌面读取，本次不提供降级迁移。
