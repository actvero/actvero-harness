# 使用工作台随包专家

[English](guide.md) | 中文

## 变更

工作台 AI 入口统一进入专家选择器。已加载且启用 AI 的工作台贡献只读专家，停用或卸载时撤下。最近明确选择的普通专家或工作台专家决定后续回合的能力，二者不叠加。空闲会话可直接切换专家；已有工作区、历史和业务数据保持原样。新关联会话不再自动创建 `.sessions/<instanceId>` 文件工作区，已有目录不会移动或删除。

工作台 API 1.9 增加专家目录元信息与本机开发连接。连接后的 dev 命令发布临时覆盖，未连接时仍只构建；正式安装和发布流程保持独立。

## 迁移

1. 从“添加 → 专家”召唤工作台提供的专家，或在“能力中心 → 专家 → 我的专家”查看来源。旧会话继续读取原关联；版本不可用时重新选择已加载专家。
2. 作者使用 `expertEntry` 提供专家名称、版本、简介和头像，设为 false 隐藏入口。使用这些字段的新包声明 `hostApi: ^1.9.0`；原有 AI 包可沿用现有注册方式。
3. 开发者从目标 Harness 导出开发连接，运行 `actvero-workbench attach /项目目录 --connection /连接文件` 后再启动 dev；用 status、logs 核对加载，detach 结束覆盖。参见[开发指南](../../../../actvero/workbench-development.zh.md#create)。
4. 升级开发套件后运行 `actvero-workbench skills update --global` 更新未被修改的共享 Skill，并用实际任务验证专家、业务对象和预览指向同一份数据。
