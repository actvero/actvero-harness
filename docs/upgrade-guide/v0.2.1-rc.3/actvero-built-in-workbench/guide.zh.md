# Actvero 默认从空工作台列表开始

[English](guide.md) | 中文

## 变更

Actvero Harness 0.1.25 移除内置「项目清单」。新安装的「我的工作台」从空列表开始。升级后仍可看到自己安装的工作台。旧清单的数据和会话历史会保留。

## 迁移

1. 打开「工作台 → 我的工作台」，确认内置「项目清单」已从列表移除。
2. 如果旧会话关联了内置清单，先取消使用该工作台，再选择一个已加载的工作台后继续对话。
3. 如需体验项目清单模板，按[工作台开发指南](../../../../actvero/workbench-development.zh.md)构建安装包并手动导入。
